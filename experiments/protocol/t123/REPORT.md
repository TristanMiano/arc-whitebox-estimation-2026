## Operational changes

| Prior tendency | New default |
|---|---|
| Consume both reserved candidate tasks | Re-rank after evidence; zero to two choices, early theory allowed |
| Rank on a fixed 100-point rubric | Expected retained official improvement per total remaining hour |
| Repeated broad experimental/scientific funnel | Usually one 12-network paired production screen; reuse existing evidence |
| More confidence or expanded gates after a point win | Roughly 90% support is enough; no added effect/interval/tier hurdle |
| Grow an uncertain test indefinitely | At most one useful extension, normally 24 total; otherwise park/recur |
| Discover executable costs after large cached runs | Meter an actual integrated full-shape fixture early |
| Native replica and fresh platform qualifications | Default Python/Whest submission path and relevant passing environment |
| Historical byte equality treated as universal | Current-package replay plus justified historical numerical equivalence |
| `.1` cost assumption acts as a hard cap | Actual adjusted score with lawful compute; retain true resource caps |
| Automatic late/near-top scientific work | Separate chosen task, named claim and finite budget |
| Fifteen-minute grading timeout in old instructions | Thirty minutes per accepted submission; one bounded unchanged retry |
| Many competing status narratives | One live state, active TODO and governing workflow; linked histories |

These are screening and work-priority rules, not new scientific claims. A
bootstrap support estimate is not a calibrated private-score probability. Data
reuse, selection and repeat looks remain disclosed. Frozen validation cannot
become a tuning set, and historical failures cannot be rewritten as passes.

The theory minimum stays at 60 active written-math minutes, with longer work
when useful. The old mandatory theory-time percentage and hypothesis-count
quota are removed. The hour must develop equations, failure boundaries,
counterexamples, cost and a decisive test; it cannot be padded with waiting.
