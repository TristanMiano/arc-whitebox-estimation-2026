# Publication rules review — October 18, 2026

The published rules and organizer clarifications permit public code and writeups during the challenge. No publication embargo or requirement to wait until Phase2 closes was found.

- [Official rules, §5.7 and §8](https://www.aicrowd.com/challenges/arc-white-box-estimation-challenge-2026/challenge_rules): public resources and LLM use are allowed, intellectual-property rights must be respected, and report authors must disclose LLM involvement and uncertainty. Place-prize recipients must release the solution and required artifacts under an OSI-approved license within the applicable deadline; that deadline is not a prohibition on earlier release.
- [Organizer clarification on public participant code](https://discourse.aicrowd.com/t/18240): licensed public code may be used with credit and substantial own changes. Keeping the MIT notices and explaining the inherited/local distinction is the stated attribution approach. Whether changes satisfy final prize/leaderboard eligibility remains the organizer's decision.
- [Writeup submission guidance](https://discourse.aicrowd.com/t/18041/4): public forum writeups are explicitly permitted, with a PDF and exactly one successfully graded submission ID. Public writeups may also be considered for community-contribution prizes where applicable.
- [October17 deadline update](https://discourse.aicrowd.com/t/18251): code closes October21, nominations October22, writeups October28, each23:59UTC. This update supersedes earlier calendar dates still visible in some rules copies.

The release preserves licenses and attribution, labels the final report a draft, and excludes credentials and challenge data caches. Publishing this GitHub repository is separate from submitting the report to the organizers or making final AIcrowd nominations. No claim of advance organizer approval or final prize eligibility is made.
