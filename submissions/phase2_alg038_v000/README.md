# ALG038-V000: CSK3-R

Unfit Gaussian linear response with persistent paired third cumulant sources, repeated-index completion and a radial fourth cumulant. All16 layers are weighted ReLUs. Physical corrected means are clipped nonnegative. The final T136 derivation and T137 registration define the estimator.

The three-level matrix kernel is reused under its retained MIT license from the public Phase1 release, as in ALG037. No fitted assets, sampling or external numerical libraries. Unsupported small matrix dimensions use tracked ordinary products.
